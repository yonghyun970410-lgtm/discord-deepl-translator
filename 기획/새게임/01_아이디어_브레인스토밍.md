# 01. 아이디어 브레인스토밍

아직 정해진 게임이 없으니, 성격이 서로 다른 후보 6개를 놓고 비교합니다.
마음에 드는 것, 섞고 싶은 것, 지우고 싶은 것을 표시해 주세요.

---

## 후보 A. 협동 로그라이트 던전
- **한 줄 소개**: 2~4명이 파티를 짜서, 매번 구조가 바뀌는 던전을 내려가며 스킬 조합을 완성한다.
- **핵심 루프**: 입장 → 층 클리어 → 보상 3개 중 1개 선택(스킬/유물) → 보스 → 사망 또는 클리어 → 영구 성장 일부 해금
- **재미 포인트**: 매 판 다른 빌드, 파티원끼리의 시너지 발견
- **MSW 적합성**: ◎ 횡스크롤 전투, 멀티 파티에 잘 맞음
- **리스크**: 밸런싱 분량이 많음, 랜덤 맵 생성 구현 필요

## 후보 B. 멀티 협동 가게 경영 (식당/여관)
- **한 줄 소개**: 친구들과 하나의 가게를 맡아 재료 수급·조리·서빙을 나눠 맡는 협동 경영 게임.
- **핵심 루프**: 영업 준비 → 손님 응대(타이머 압박) → 정산 → 가게 확장·레시피 해금
- **재미 포인트**: 정신없는 협업, 역할 분담, 가게 꾸미기
- **MSW 적합성**: ○ 소셜성 좋음, 꾸미기 콘텐츠로 장기 플레이 유도
- **리스크**: 리프월드와 "운영" 감각이 일부 겹칠 수 있음 → 실시간 액션 위주로 차별화

## 후보 C. 소셜 추리 게임
- **한 줄 소개**: 8~12명 중 숨어 있는 배신자를 찾아내는 대화·추리형 파티 게임 (독자 세계관/규칙).
- **핵심 루프**: 역할 배정 → 임무 수행 + 방해 → 회의·투표 → 승패
- **재미 포인트**: 거짓말과 심리전, 방송·친구 모임에서 반응이 큼
- **MSW 적합성**: ◎ 채팅·다인원 접속에 유리, 콘텐츠 양 대비 플레이 시간이 김
- **리스크**: 동시 접속 인원 확보가 필수, 장르 내 차별점(고유 역할/맵 기믹) 설계가 핵심

## 후보 D. 액션 디펜스
- **한 줄 소개**: 타워를 세우는 동시에 플레이어 캐릭터가 직접 싸우며 웨이브를 막는다.
- **핵심 루프**: 준비 시간(건설/강화) → 웨이브 방어(직접 전투) → 보상 → 다음 스테이지
- **재미 포인트**: 전략 + 손맛 동시, 솔로·협동 모두 가능
- **MSW 적합성**: ○ 스테이지 단위 제작이 쉬워 콘텐츠를 늘리기 편함
- **리스크**: 횡스크롤 화면에서 디펜스 동선을 읽기 쉽게 만드는 레벨 디자인

## 후보 E. 채집·수집 힐링 게임
- **한 줄 소개**: 낚시·채집·곤충 채집 등으로 도감을 채우고, 결과물로 섬/집을 꾸민다.
- **핵심 루프**: 채집 → 판매/제작 → 도감·꾸미기 → 새 지역 해금
- **재미 포인트**: 수집욕, 희귀 개체, 부담 없는 플레이
- **MSW 적합성**: ○ 짧게 접속해도 할 거리가 있음
- **리스크**: 콘텐츠(개체 수, 아트) 물량이 필요, 장기 목표 설계

## 후보 F. 파티 레이스 플랫포머
- **한 줄 소개**: 장애물 코스를 여러 명이 동시에 달려 서바이벌로 탈락시키는 짧은 라운드형 게임.
- **핵심 루프**: 대기실 → 라운드 3~5개(레이스/생존/팀전) → 최종 1인 → 보상·코스튬
- **재미 포인트**: 짧고 직관적, 몸개그, 관전 재미
- **MSW 적합성**: ◎ 플랫포머 물리 활용, 맵 하나 = 라운드 하나라서 확장 용이
- **리스크**: 인원 확보, 네트워크 판정(동기화) 품질

## 방향을 좁히기 위한 질문

1. 혼자 해도 재미있는 게임인가, 여럿이 모여야 재미있는 게임인가?
2. 한 판의 길이: 5분 / 20분 / 끝없이 계속?
3. 손맛(액션) vs 머리(전략·경영) vs 사람(소통·심리) 중 무엇이 중심인가?
4. 목표 개발 기간: 1개월 프로토타입? 3~6개월 정식 출시?
5. 리프월드에서 만든 시스템(인벤토리, AI, 저장 등) 중 **개념만** 재활용하고 싶은 것이 있는가?
